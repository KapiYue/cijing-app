Free Dictionary API 与 Wiktionary

英文释义、音标及部分真人发音由 Free Dictionary API 提供。词条通常源自 Wiktionary，并按 Creative Commons Attribution-ShareAlike 3.0 提供。

词鲸只使用同时带有来源和许可信息的词条。查词结果、阅读查词结果和已收藏词条会保留具体词条来源与许可链接。对这些词条进行翻译、整理或其他改编时，相应改编部分继续按适用的同方式共享许可提供。

发音素材

部分真人发音来自 Wikimedia Commons 等来源，可能分别采用 CC BY、CC BY-SA 的不同版本。词鲸只播放同时带有发音来源和独立许可的音频；具体作者页面和许可会显示在对应查词结果中。无法确认许可时使用设备或浏览器系统语音。

OpenRouter 与 Qwen

中文语境解释、例句和个性化双语短文由所配置的 Qwen3.6 Flash 模型经 OpenRouter 生成。请求只允许路由到声明不收集输入用于训练的端点。
