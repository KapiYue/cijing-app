一、我们处理的信息

1. 账号与资料

注册、登录和账号安全所需的邮箱地址、密码，以及 Supabase Auth 生成的用户标识和会话信息。密码由 Supabase Auth 验证，词鲸业务数据库和 AI 服务不保存或接收明文密码。我们还会保存你主动填写的昵称、每日目标、阅读难度、主题、文体及发音偏好。

2. 学习与用户内容

  • 查询或收藏的单词、释义、音标、例句、笔记、自定义释义和学习状态；
  • 你选择查询的网页单词，以及最多 1800 字符的周边文本、最多 600 字符的句子、页面标题和来源 URL；
  • 复习质量分、练习类型、答案、预期答案、响应时间、复习间隔及到期时间；
  • AI 生成的双语短文、目标词、阅读进度、练习结果和学习活动汇总。

只有在扩展设置允许时保存网页语境。开启“隐私模式”后，扩展会在发出查词请求前清空上下文、句子、页面标题和来源 URL。

3. 麦克风与语音识别

只有在你主动开始跟读时，iOS 才请求麦克风和语音识别权限。当前版本把录音暂存在设备临时目录，用 Apple 系统语音识别得到文字并计算本次准确度；完成识别、取消或离开功能后删除临时录音。当前版本不会把录音或识别文字上传到词鲸业务数据库，也不会后台持续录音。

Apple 的语音识别可能根据设备、语言和系统设置在设备端或通过 Apple 服务处理，具体以系统权限提示、设备设置及 Apple 政策为准。关闭权限只影响跟读识别。

4. 本地设置、网络与诊断

客户端会在设备上保存登录会话、本地缓存、主题、隐私模式、是否保存语境和禁用网站列表等必要设置。iOS 的显示模式、提醒、自动发音和触感开关按账号在本机隔离保存，当前不会随账号跨设备同步。开启每日提醒后，App 会请求系统通知权限并在设备上安排每天 20:30 的重复本地通知；关闭提醒、退出登录或删除账号时会移除该调度。网络请求还可能自然包含 IP 地址、设备/浏览器及系统版本、请求时间和必要错误信息，用于传输、安全防护、限流、稳定性和排障。

政策与支持网站为静态页面，当前没有注册、表单、广告、分析或追踪功能；托管服务仍可能为传输和安全目的产生标准访问日志。

二、使用目的

  1. 创建、验证和保护账号，维持登录及跨端同步；
  2. 提供查词、收藏、个人词库、笔记和来源语境；
  3. 生成词义补充、例句和个性化双语分级短文；
  4. 安排间隔复习，记录练习并展示学习进度；
  5. 提供系统发音、跟读识别和本次准确度反馈；
  6. 响应支持请求，防止滥用，排查故障并保障服务安全；
  7. 履行适用法律义务并保护重大合法权益。

需要系统权限、单独同意或其他特别授权时，我们会在相关功能前说明。拒绝非核心权限只影响依赖该权限的功能。

四、保存期限、存储地点与跨境处理

  • 账号及学习数据通常在账号存续和提供功能所需期间保存；
  • 查词 AI 结果按用户和上下文隔离，默认缓存 90 天；
  • 跟读临时录音在识别完成、取消或功能清理时从设备临时目录删除；
  • 设备缓存和偏好保留到你清理、退出登录、重置扩展数据或卸载客户端；
  • 安全日志、备份或依法必须保存的信息只在相应目的的必要期限内保留，期满后删除或匿名化。

账号删除会删除 Supabase Auth 用户，并级联删除个人资料、词库、语境、复习、短文、练习、活动和用户级缓存。已进入短期备份轮转、依法必须保留或为调查安全事件必须保留的有限记录，可能在相应必要期限届满后完成清除。

云服务、AI 服务或 Apple 系统服务的基础设施可能位于你所在国家或地区之外，实际地点由项目区域、模型路由和系统服务决定。发生适用法律所定义的跨境提供时，我们会限制到实现功能所需范围，并履行相应告知、同意或其他法定义务。

五、安全措施

我们采用传输加密、身份认证、最小权限、服务端 secret 隔离、数据库 Row Level Security、按用户缓存隔离、输入长度限制和账号删除级联等措施。客户端只包含 Supabase URL 与 publishable key，不包含 Supabase secret key 或 OpenRouter API key。

互联网服务无法保证绝对安全。若发生可能影响你权益的个人信息安全事件，我们会采取补救措施，并按适用法律告知相关情况和降低风险的建议。

六、你的权利与账号删除

在适用法律范围内，你可以请求访问、复制、更正、补充、删除或限制处理个人信息，撤回可选授权，注销账号，并要求说明处理规则。你可以在 App 修改资料与偏好，在系统设置关闭麦克风或语音识别，在 App 清理缓存，并在扩展关闭语境保存或开启隐私模式。

App 内删除路径：设置 → 点击顶部个人资料 → 账户安全 → 删除账号。输入当前登录邮箱并二次确认后立即提交删除。账号及云端学习数据会被永久删除，无法恢复。

无法登录时，请使用注册邮箱联系 zdjoey@126.com。为保护账号，我们可能先核验身份。

七、未成年人

未满十四周岁的用户应在监护人同意和指导下使用。监护人应帮助未成年人理解本政策、谨慎提供网页上下文，并管理麦克风与语音识别权限。如果发现未经监护人同意处理了不满十四周岁未成年人的个人信息，我们会在核实后尽快删除或采取其他必要措施。
