# 词鲸背单词支持与帮助

更新日期：2026 年 7 月 30 日

支持邮箱：[`zdjoey@126.com`](mailto:zdjoey@126.com)。联系时请勿发送密码、验证码、访问令牌、secret key、完整朗读录音或包含他人私人内容的网页文本。

## 快速排查

### 无法注册或登录

确认邮箱格式正确、密码不少于 8 位且网络稳定。如果页面提示邮箱尚未确认，请先完成验证邮件中的步骤。iOS App 和扩展需要连接同一个 Supabase 环境；普通用户不应修改连接地址或 API key。

### 登录后看不到原来的词库或短文

确认使用的是原来的邮箱，并检查网络。下拉刷新或重启 App 后，首页应重新加载该账号的云端词库和 `reading_sessions` 历史。如果刚切换开发/生产环境，相同邮箱在两个环境中也是不同账号。

### AI 查词或短文生成失败

检查网络后稍后重试。一次生成失败不会删除已经保存的词库与短文。若只有罕见单词失败，请提供该单词；若所有 AI 功能同时失败，请提供发生时间、客户端版本和错误提示，不要提供账号密码。

### 扩展没有弹出查词卡片

在 `chrome://extensions` 确认扩展已启用并刷新，检查当前站点是否在“暂停的网站”列表。浏览器内部页、扩展商店、部分 PDF 或禁止脚本注入的页面可能无法使用内容脚本。隐私模式不会关闭查词，但会停止发送网页上下文和来源。

### 如何关闭网页语境保存

在扩展弹窗或设置中关闭“保存网页语境”。如希望查询时也不发送周边文本，开启“隐私模式”；该模式会在请求发出前清空上下文、句子、页面 URL 和标题。

### 麦克风或语音识别不可用

前往 iOS/iPadOS“设置 → 隐私与安全性 → 麦克风/语音识别”，允许词鲸使用相应权限。结束一次跟读后，App 会删除设备临时目录中的录音。关闭权限只影响跟读识别，不影响系统发音、查词、词库和阅读。

### 如何清理缓存

在 App 中打开“设置 → 关于 → 清理缓存”。该操作删除设备上的临时数据，不会删除云端词库与学习记录。扩展本地设置可通过扩展管理页清除；清除后需要重新登录和设置偏好。

## 删除账号与数据

**App 内路径：设置 → 点击顶部个人资料 → 账户安全 → 删除账号。**

输入当前登录邮箱并完成二次确认后，会永久删除 Supabase Auth 账号，并级联删除个人资料、词库、网页语境、复习记录、AI 短文、阅读进度、练习、学习活动和用户缓存，无法恢复。删除前请自行保存仍需要的内容。

如果无法登录，请使用注册邮箱联系 [`zdjoey@126.com`](mailto:zdjoey@126.com)。为防止未经授权删除，我们会先核验账号归属。

- 问题发生日期、时间和所在时区；
- App/扩展版本与 iOS、iPadOS 或 Chrome 版本；
- 使用的是 iOS、iPadOS 还是 Chrome 扩展，以及能稳定复现的步骤；
- 完整错误文字和已隐藏邮箱、网页内容等私人信息的截图；
- 注册邮箱仅在确需定位账号时提供，绝不要提供密码或令牌。

我们通常会在 7 个工作日内确认收到，但复杂问题的解决时间取决于复现、第三方服务和必要的身份核验。安全漏洞请按照仓库 [`SECURITY.md`](../SECURITY.md) 私下报告，不要创建包含利用细节或用户数据的公开 Issue。
