# 词鲸背单词隐私政策

更新日期：2026 年 7 月 30 日  
生效日期：2026 年 7 月 30 日

本政策适用于“词鲸背单词”iOS App、配套 Chrome 扩展以及只读政策与支持网站（以下统称“词鲸”）。我们按照合法、正当、必要和诚信原则处理个人信息，不出售个人信息，当前版本不接入广告或跨 App/网站追踪 SDK。

如对本政策或个人信息处理有疑问，请联系词鲸运营者：[`zdjoey@126.com`](mailto:zdjoey@126.com)。

## 一、我们处理的信息

### 1. 账号与资料

- 注册、登录和账号安全所需的邮箱地址、密码及 Supabase Auth 生成的用户标识和会话信息；密码由 Supabase Auth 验证，词鲸业务数据库和 AI 服务不保存或接收明文密码。
- 你主动填写的昵称、每日新词/复习目标、阅读难度、主题、文体及发音偏好。

### 2. 学习与用户内容

- 查询或收藏的单词、释义、音标、例句、笔记、自定义释义和学习状态；
- 你选择查询的网页单词，以及最多 1800 字符的周边文本、最多 600 字符的句子、页面标题和来源 URL；只有在扩展相关设置允许时保存网页语境，开启“隐私模式”后会在发出查词请求前清空上下文和页面来源；
- 复习质量分、练习类型、答案、预期答案、响应时间、复习间隔及到期时间；
- AI 生成的标题、双语短文、目标词、阅读进度、练习结果和学习活动汇总。

### 3. 麦克风与语音识别

只有在你主动开始跟读时，iOS 才请求麦克风和语音识别权限。当前版本把录音暂存在设备临时目录，用 Apple 系统语音识别得到文字并计算本次准确度；完成识别、取消或离开功能后删除临时录音。当前版本不会把录音或识别文字上传到词鲸业务数据库，也不会后台持续录音。

Apple 的语音识别可能根据设备、语言和系统设置在设备端或通过 Apple 服务处理，具体以系统权限提示、设备设置及 Apple 政策为准。关闭权限后，跟读识别不可用，但系统发音、查词、词库和阅读仍可使用。

### 4. 本地设置、网络与诊断信息

iOS App 和扩展会在设备上保存登录会话、本地缓存、界面主题、隐私模式、是否保存语境、禁用网站列表等必要设置。iOS 的显示模式、提醒、自动发音和触感开关按账号在本机隔离保存，当前不会随账号跨设备同步。网络请求还可能自然包含 IP 地址、设备/浏览器及系统版本、请求时间和必要错误信息，用于传输、安全防护、限流、稳定性和故障排查。

政策与支持网站为静态页面，当前不提供注册、表单、广告、分析或追踪功能；托管服务仍可能为传输和安全目的产生标准访问日志。

## 二、使用目的

我们仅在以下目的所需范围内处理信息：

1. 创建、验证和保护账号，维持登录及跨端同步；
2. 提供查词、收藏、个人词库、笔记和来源语境；
3. 生成词义补充、例句和个性化双语分级短文；
4. 安排间隔复习，记录练习并展示学习进度；
5. 提供系统发音、跟读识别和本次准确度反馈；
6. 响应支持请求，防止滥用，排查故障并保障服务安全；
7. 履行适用法律义务，响应有权机关的合法要求，保护用户、词鲸或公众的重大合法权益。

需要系统权限、单独同意或其他特别授权时，我们会在相关功能前说明。你可以拒绝非核心权限；拒绝只影响依赖该权限的功能。

## 三、委托处理、第三方服务与对外提供

为实现功能，必要信息可能由以下服务处理：

| 服务 | 用途 | 可能处理的信息 |
| --- | --- | --- |
| Supabase | Auth、数据库、访问控制、同步与 Edge Functions | 邮箱、用户标识、会话及云端学习数据 |
| OpenRouter 与所配置的 Qwen 模型 | 中文词义补充、语境解释、个性化短文 | 所选单词、受限长度的句子/上下文、目标词释义和阅读选项 |
| Free Dictionary API | 公开英文释义、音标和发音来源 | 查询的英文单词 |
| Apple 系统能力 | 语音合成、麦克风权限与语音识别 | 本次朗读音频及识别请求，具体由系统决定 |

我们不会向 AI 服务发送邮箱、密码、访问令牌或完整浏览历史。除上述完成服务所必需的处理外，我们不会出售个人信息，也不会为第三方广告或跨服务画像提供个人信息。

发生合并、分立、重组、资产转让或服务运营主体变更时，如涉及个人信息转移，我们会依法告知接收方，并要求其继续受本政策约束；处理目的或方式改变时将重新取得所需授权。法律要求、司法或行政机关依法提出要求，或为保护重大合法权益确有必要时，我们可能提供最少必要信息。

## 四、保存期限、存储地点与跨境处理

- 账号及学习数据通常在账号存续和提供功能所需期间保存；
- 查词 AI 结果按用户和上下文隔离，默认缓存 90 天，之后不再作为有效缓存使用；
- 跟读临时录音在识别完成、取消或功能清理时从设备临时目录删除；
- 设备缓存和偏好保留到你清理缓存、退出登录、重置扩展数据或卸载客户端；
- 安全日志、备份或依法必须保存的信息仅在实现相应目的的必要期限内保留，期满后删除或匿名化。

账号删除会删除 Supabase Auth 用户，并通过数据库外键级联删除其个人资料、词库、语境、复习、短文、练习、活动和用户级缓存。已经进入短期备份轮转、依法必须保留或为调查安全事件必须保留的有限记录，可能在相应必要期限届满后完成清除。

云服务、AI 服务或 Apple 系统服务的基础设施可能位于你所在国家或地区之外。实际地点由所选项目区域、模型路由和系统服务决定。发生适用法律所定义的跨境提供时，我们会限制到实现功能所需范围，并履行相应的告知、同意或其他法定义务。

## 五、安全措施

我们采用传输加密、身份认证、最小权限、服务端 secret 隔离、数据库 RLS、按用户缓存隔离、输入长度限制和账号删除级联等措施。客户端只包含 Supabase URL 与 publishable key，不包含 Supabase secret key 或 OpenRouter API key。

任何互联网服务都无法保证绝对安全。若发生可能影响你权益的个人信息安全事件，我们会采取补救措施，并按适用法律告知事件情况、可能影响、已采取措施和可降低风险的建议。

## 六、你的权利与账号删除

在适用法律范围内，你可以请求访问、复制、更正、补充、删除或限制处理个人信息，撤回可选授权，注销账号，并要求说明个人信息处理规则。你可以：

- 在 App 个人资料与偏好页面查看或更正相应内容；
- 在系统设置中关闭麦克风或语音识别权限；
- 在 App 内清理本机缓存，在扩展设置中关闭语境保存或开启隐私模式；
- 通过支持邮箱提出无法自行完成的权利请求。为保护账号，我们可能先核验身份。

**App 内删除路径：设置 → 点击顶部个人资料 → 账户安全 → 删除账号。** 输入当前登录邮箱并二次确认后立即提交删除。该操作会永久删除账号及云端学习数据，无法恢复。

如果无法登录，可使用注册邮箱联系 [`zdjoey@126.com`](mailto:zdjoey@126.com)。
